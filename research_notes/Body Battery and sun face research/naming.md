# Naming

Store keyword search (US, watch faces and all types), 2026-09-26. "Contains-hit" = an app whose English name contains the candidate. The search is relevance-ranked and capped near 90 results per query, so "no hit" is **not** proof of no collision, and **no trademark search was done**.

| Candidate | Contains-hits | Notes |
|---|---|---|
| **Two Suns** | 0 | The sky's sun and your own. Memorable; says nothing about what it does, so the listing carries the meaning |
| Sun Battery | 0 | Says both things in two words; "Battery" invites confusion with a device-battery face |
| Daybank | 0 | Daylight and energy as a balance; unusual spelling risk |
| Sunbank | 0 | Same idea |
| Sunspend / Sunfuel / Sunpace | 0 | Awkward |
| Spend the Day | 0 | Phrase, not a name |
| Day Charge, Solar Charge, Sun and Charge | 0 | Clear; "Solar Charge" reads as solar charging of the watch (fēnix Solar) |
| Dawn to Dusk | 0 | Descriptive |
| Second Sun, Inner Sun, Last Light, Sunwise | 0 | |
| Daylight Budget | **1** (1 download, 2026-08-24) | A stub with the same idea; avoid |
| First Light | 3 (a 10-download face and two 007 faces) | Avoid |
| Golden Hour | 5 (100 downloads at most) | Avoid; also a photography term rivals use |
| Sunlit | 12 (sunlit-prefixed faces) | Avoid |

**Body Battery is Garmin's trademark ("Body Battery™").** A face called "Body Battery" already exists (10 downloads, 2.99). Use the term only descriptively in the listing ("shows your watch's Body Battery"), never in the name, icon or as the product's brand, and never imply Garmin endorsement. Ask the owner whether they want a trademark check.

**Recommendation:** working name **Two Suns**, slug `two-suns`, folder `TwoSuns/`. Runner-up: **Sun Battery**. The slug is permanent once a site page is published; the folder can be renamed with `mv` until the first commit.
