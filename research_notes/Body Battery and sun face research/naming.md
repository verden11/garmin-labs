# Naming

Store keyword search (US, watch faces and all types), 2026-09-26. "Contains-hit" = app whose English name contains candidate. Search relevance-ranked, capped near 90 results per query, so "no hit" **not** proof of no collision, **no trademark search was done**.

| Candidate | Contains-hits | Notes |
|---|---|---|
| **Two Suns** | 0 | Sky's sun + your own. Memorable; says nothing about function, so listing carries meaning |
| Sun Battery | 0 | Says both things in two words; "Battery" invites confusion with device-battery face |
| Daybank | 0 | Daylight + energy as balance; unusual spelling risk |
| Sunbank | 0 | Same idea |
| Sunspend / Sunfuel / Sunpace | 0 | Awkward |
| Spend the Day | 0 | Phrase, not name |
| Day Charge, Solar Charge, Sun and Charge | 0 | Clear; "Solar Charge" reads as solar charging of watch (fēnix Solar) |
| Dawn to Dusk | 0 | Descriptive |
| Second Sun, Inner Sun, Last Light, Sunwise | 0 | |
| Daylight Budget | **1** (1 download, 2026-08-24) | Stub, same idea; avoid |
| First Light | 3 (10-download face, two 007 faces) | Avoid |
| Golden Hour | 5 (100 downloads at most) | Avoid; also photography term rivals use |
| Sunlit | 12 (sunlit-prefixed faces) | Avoid |

**Body Battery = Garmin trademark ("Body Battery™").** Face called "Body Battery" already exists (10 downloads, 2.99). Use term only descriptively in listing ("shows your watch's Body Battery"), never in name, icon or as product brand, never imply Garmin endorsement. Ask owner if trademark check wanted.

**Recommendation:** working name **Two Suns**, slug `two-suns`, folder `TwoSuns/`. Runner-up: **Sun Battery**. Slug permanent once site page published; folder renamable with `mv` until first commit.
