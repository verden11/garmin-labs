### Inferences
- The dominant constraint is not engineering: it is that no demand signal exists yet for either live app, and SELL says the store rewards recency/velocity plus listing metadata, not more listings. Building products 3–5 before Gate 0 reads out repeats the risk OB already flags for Habits and Ready (thin differentiation), at solo capacity.
- Ranking 1–3 is by (evidence grade × reuse of shipped code × low new-permission surface). Connect sync ranks first only because it is the one feature with cited competitor-review evidence and it is already written; it is verification work, so it also competes for the same FR965 wrist time as Gate 0's accuracy proof (order: accuracy proof, then sync spike).
- Body Battery/Stress/Training Status inside HeroFace via the complication route reaches the same user need as Ready and Pace Face at ~zero marginal permission and product cost, but only on the 66 CIQ 4.2+ products (HF-COMPAT).
- OB effort estimates are code-only and unmeasured (its own header: "not implemented or verified here"); treat them as lower bounds.
