One question at a glance: how much light, how much energy left today? 24-hour ring = sky's sun, 24-hour curve under time = watch's own Body Battery, one sentence at bottom = light left or next sunrise. 72 products (66 round, 3 rectangular AMOLED, 3 Instinct E / 3 Solar with round window), API 4.2+, `minApiLevel` 4.2.0, permissions `SensorHistory`, `ComplicationSubscriber`, `Positioning`. **Live since 2026-09-28** (1.0.0, approved that day): https://apps.garmin.com/apps/9d4bca45-d79a-4f26-abf5-04e0519cf10b (Garmin's own app id, distinct from manifest AppID below). ## Fast facts

- Independent of HeroSet, HeroFace, Days To Go: own app id (`6c3c5a3d-b312-4c0f-bf37-2a3fc3a79580`, never changes once published), no complication publishing, no shared code (calendar, layout, sleep patterns copied from Days To Go).
- **Sunrise and sunset = Garmin's own numbers** (`Complications` SUNRISE and SUNSET, local seconds since midnight). Own NOAA calculation (`TwoSunsSun`) fills what Garmin does not give: tomorrow's sunrise, twilight, golden hour, polar days, a null. `Weather.getSunrise` not called.
- **Body Battery** = `SensorHistory` (24 h, 96 buckets of 15 min) plus Complication number as fallback. No verdicts, no mood, no advice on it, ever. "Body Battery" is Garmin's trademark: never in name, icon or brand; phone setting says "Energy curve".
- Local UTC offset derived exactly from clock (`TwoSunsLocalTime.offsetBetween`), not from `System.getClockTime().timeZoneOffset`.
- Only `Application.Storage` use: remembered place, `[lat, lon]` rounded to 0.1 degree, key `place`. Never sent anywhere. **Pro only: Free build keeps no place, writes no `Application.Storage`, reads no location (saves only accent colour, a Properties setting).** Settings are Properties, lists only, re-read on every update.
- **Tier-only code is `(:pro)` / `(:free)`** (a `(:free)` twin returns null, empty list or does nothing). Compiler checks permissions at call sites, so Free jungle compiling proves no `SensorHistory` or `Positioning` call in it; `Position`, `SensorHistory`, `Weather`, `Activity` not imported (import cannot be annotated), named in full inside `(:pro)` functions. Free never reads or writes a Pro property key (`getValue` and `setValue` of missing key throw `InvalidKeyException`: SDK docs, not observed here). `AppName` lives only in `resources-free/strings` and `resources-pro/strings`, never in `resources/` or a `resources-<lang>/`; each jungle appends its tier folder to every `base.lang.<l>`; settings files live only in `resources-free/settings` and `resources-pro/settings`.
- Free's Body Battery = Garmin's number only: `--` and hollow bolt when null, never stale state (Complication has no timestamp), ADR-021 (Body Battery in Free). Free never says "No place yet" ("No sun data" instead).
- **`Position.getInfo` isolated in `TwoSunsSources.positionLocation`** (Pro only). Calling it without Positioning permission kills app, cannot be caught. If permission dropped, delete that function and its entry in `updatePlace()`.
- Property keys `Accent`, `Orientation`, `Golden`, `Curve`, `Date`, `Weather`, `Battery` and Storage key `place` never change once shipped.
- **Weather row (Pro, ADR-022):** `Toybox.Weather` read only in `TwoSunsWeatherSource` (named in full, `(:pro)`, cached 5 minutes); plan, kinds, icons, row = pure or primitive-drawn `(:pro)` classes; `TwoSunsWeather` is the one shared class (so `TwoSunsState` compiles in Free, which never builds one). Feels-like only (temperature when missing); hourly entry whose hour ended, reading older than 3 hours, condition with no icon left out. Weather hues `#FFFF55` and `#00AAFF` reserved: no accent may equal them.
- Build (Pro; `monkey.free.jungle` is Free): `monkeyc -d fr965 -f monkey.jungle -o bin/TwoSuns.prg -y ~/.garmin-connectiq/keys/developer_key -w --typecheck 3`
- **Instinct E / 40 / 45 mm and 3 Solar (ADR-024, accepted 2026-10-04, simulator only, look approved 2026-10-04; 72 products now):** 1-bit, round window top right, 65,536 B face memory. `TwoSunsPalette` = two classes, `(:color)` and `(:mono)`, chosen by jungles (`base.excludeAnnotations = <tier>;mono;norect`, per Instinct product `<product>.excludeAnnotations = <tier>;color;rect`; per-product line **replaces** base list, so restate tier's own). ## House rules

Same as Days To Go ([`../DaysToGo/CLAUDE.md`](../DaysToGo/CLAUDE.md)) and HeroFace ([`../HeroFace/CLAUDE.md`](../HeroFace/CLAUDE.md)), which this project mirrors:

- Every function: typed params and `as` return type. No `as Any`. Cast only after `instanceof` or null guard.
- No magic numbers: tunables and keys in `TwoSunsConfig`, geometry in `TwoSunsLayout`, colours in `TwoSunsPalette`, words in `strings.xml`.
- Text fit measured, never guessed: draw through `TwoSunsDraw`.
- Render only in `onUpdate`; gather in `TwoSunsSources`/`TwoSunsReadings`, draw from `TwoSunsState`.
- One class per file, `TwoSuns` prefix. Functions ≲30 lines, files ≲250.
- Value watch lacks = hidden or said in words, never faked or blank ("No place yet", "No sun data", `--`).
- Forbidden here: `Weather.getSunrise` as primary source; `date` or `numeric` settings; any mood, emoji or advice tied to Body Battery; network; `Background`, `Communications`, `UserProfile`; seconds; storing anything but rounded place; permissioned call outside manifest that declares it. Add nothing from spec's non-goals (weather no longer one: ADR-022, Weather row in Pro, Proposed, owner-overridden 2026-10-03, built and in Pro 1.1.0 upload; `Weather` still named in full inside `(:pro)` functions).
- Warnings and strict typing on, zero warnings (`-w --typecheck 3`; only accepted notices: launcher-icon scaling until real icon ships).
- Do not invent evidence: no reviews, downloads, screenshots, battery figures or accuracy claims about Body Battery, in any doc or listing. Say "simulator only" wherever claim rests on simulator.
