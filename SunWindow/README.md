# Sun Window

A free Garmin app with a glance that shows whether the sun is at or above 45
degrees right now: OPEN, CLOSED or NONE TODAY.

Status: unbuilt (spec and plan only, 2026-10-05).

## Layout

- `source/`, `resources/` — Monkey C source and resources (not created yet).
- `docs/` — spec, ADRs, status and gates, release contract, compatibility, development (index: `docs/README.md`).
- `listing/` — store form text (`paste.md`), metadata (`meta.yaml`) and rationale (`NOTES.md`).
- `DESIGN.md` — visual system (filled at plan task P2.6).
- `CHANGELOG.md` — one entry per store publication.

See [`docs/spec.md`](docs/spec.md) for what this app does,
[`docs/status.md`](docs/status.md) for where it stands and what's left,
and [`../reports/Sun Window build plan.md`](../reports/Sun%20Window%20build%20plan.md) for the task plan.
